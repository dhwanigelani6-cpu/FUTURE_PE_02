
# AI Content Marketing Using UGC Ads

## Future Interns – Prompt Engineering Task 2

### Project Overview
This project demonstrates AI-powered UGC (User-Generated Content) advertising for a fictional lipstick brand called Velvet Glow. It includes marketing hooks, short-form ad scripts, platform-specific captions, calls to action, and AI video-generation prompts.

### Objective
- Generate engaging UGC-style ad scripts.
- Create multiple hooks for the same product.
- Apply the Problem–Solution–CTA framework.
- Adapt marketing content for Instagram Reels, Facebook, and YouTube Shorts.
- Document reusable prompts and AI-generated outputs.

### Product Details
- Brand: Velvet Glow (fictional)
- Product: Velvet Matte Lipstick
- Category: Beauty and Cosmetics
- Audience: Adult beauty and makeup consumers
- Campaign Goal: Product awareness and audience engagement

### Tools Used
- ChatGPT – Prompt engineering and ad copywriting
- GitHub – Project documentation and version control
- Google Flow – Optional AI video generation
- Canva – Optional promotional design and editing

### Key Deliverables
1. UGC Ad Content Pack
2. AI Video Prompt Generator
3. Lipstick Video Shot List
4. Reusable UGC Script Prompt
5. Platform-Specific Social Media Outputs
6. Final Advertising Video (optional)

### Project Structure

### Marketing Framework
Problem: Consumers want inspiration for choosing a lipstick shade.
Solution: Present the fictional lipstick product through engaging visuals and relatable content.
CTA: Invite viewers to explore the collection.

### Learning Outcomes
- Structured prompt writing
- UGC ad scripting
- Marketing hooks and CTAs
- Platform-specific content creation

- GitHub documentation

This project demonstrates how structured prompts can support the creation of engaging, platform-specific marketing content.
